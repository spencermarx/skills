# Quality bar

Work this list item by item before calling the design done. Each one is passed
explicitly, or waived explicitly with a reason. An item skipped in silence is an
item that failed.

- [ ] **Hierarchy is unambiguous.** A new user identifies the primary action
      within 200ms.
- [ ] **No visual noise.** Every border, shadow, color, and icon serves a
      purpose.
- [ ] **States are handled.** Empty, loading, error, and success are designed
      rather than defaulted.
- [ ] **Spacing is intentional.** The spacing scale is used consistently, with no
      arbitrary pixel values.
- [ ] **Typography is disciplined.** A clear size and weight hierarchy, with at
      most three or four distinct text styles per component.
- [ ] **Color is semantic.** Colors carry meaning rather than decoration.
- [ ] **Interactions feel alive.** Hover, focus, and active states exist on every
      interactive element.
- [ ] **Accessibility is met.** Sufficient contrast, keyboard navigation,
      semantic HTML, and ARIA where visual context alone is insufficient.
- [ ] **Responsive design works.** The layout adapts gracefully at 375px, 768px,
      and 1280px and above.
- [ ] **The design system is respected.** Existing components and tokens are
      used, with no rogue styles.
- [ ] **The stressed user succeeds.** The design works for someone distracted,
      rushed, and on mobile.
- [ ] **Code compiles cleanly.** No type errors, no missing imports, no broken
      references.
