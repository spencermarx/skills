# HTML Template Architecture

This document defines the complete HTML/CSS/JS structure for every slide deck. Generate the entire file following this specification. The output is a single self-contained HTML file with all CSS and JS inline.

## Document Structure

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>{Deck Title}</title>
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  <!-- The web-font link the brand kit's typography names -->
  <link href="{web-font URL from the brand kit}" rel="stylesheet" />
  <style>
    /* ============================================
       1. VIEWPORT BASE CSS
       Paste the FULL contents of references/viewport-base.css here,
       with its :root token block filled from the brand kit.
       Change nothing else.
       ============================================ */

    /* ============================================
       2. SLIDE-TYPE OVERRIDES
       Add slide-type-specific CSS here based on
       which types this deck uses.
       ============================================ */
  </style>
</head>
<body>
  <div class="presentation">

    <!-- Each slide is a <section> -->
    <section class="slide slide--{type}">
      <div class="slide-content">
        <!-- Slide content with .reveal classes -->
      </div>
      <div class="slide-footer">
        <div class="footer-logo">
          <!-- Inlined brand logo SVG (see Logo Embedding below) -->
        </div>
        <span class="footer-title">{Deck Title}</span>
      </div>
    </section>

    <!-- Repeat for each slide -->

  </div>

  <!-- Navigation chrome -->
  <div class="progress-bar"><div class="progress-fill"></div></div>
  <nav class="nav-dots" aria-label="Slide navigation">
    <!-- Generated by JS -->
  </nav>

  <script>
    /* SlidePresentation controller (see JS Controller below) */
  </script>
</body>
</html>
```

## Logo Embedding

Read the logo SVG from the path the brand kit's logos reference documents. On dark-background slides, use the light-on-dark variant it names. Never copy a logo path into this file: the brand kit owns it, and a copy here is the drift the brand kit exists to prevent.

Inline the raw SVG markup directly into the `.footer-logo` div of every slide footer. Set `height="20"` and `width="auto"` on the `<svg>` element.

## JS Controller: `SlidePresentation`

Paste this complete class into the `<script>` block. It handles all navigation, animations, and UI chrome.

```javascript
class SlidePresentation {
  constructor() {
    this.slides = document.querySelectorAll('.slide');
    this.currentSlide = 0;
    this.isScrolling = false;

    this.setupIntersectionObserver();
    this.setupKeyboardNav();
    this.setupTouchNav();
    this.setupProgressBar();
    this.setupNavDots();
    this.animateCounters();

    // Mark first slide as visible on load
    if (this.slides.length > 0) {
      this.slides[0].classList.add('visible');
    }
  }

  setupIntersectionObserver() {
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add('visible');
          this.currentSlide = Array.from(this.slides).indexOf(entry.target);
          this.updateProgressBar();
          this.updateNavDots();
        }
      });
    }, { threshold: 0.5 });

    this.slides.forEach(slide => observer.observe(slide));
  }

  setupKeyboardNav() {
    document.addEventListener('keydown', (e) => {
      switch (e.key) {
        case 'ArrowDown':
        case 'ArrowRight':
        case ' ':
        case 'PageDown':
          e.preventDefault();
          this.goToSlide(this.currentSlide + 1);
          break;
        case 'ArrowUp':
        case 'ArrowLeft':
        case 'PageUp':
          e.preventDefault();
          this.goToSlide(this.currentSlide - 1);
          break;
        case 'Home':
          e.preventDefault();
          this.goToSlide(0);
          break;
        case 'End':
          e.preventDefault();
          this.goToSlide(this.slides.length - 1);
          break;
        case 'f':
        case 'F':
          if (!e.metaKey && !e.ctrlKey) {
            e.preventDefault();
            this.toggleFullscreen();
          }
          break;
      }
    });
  }

  setupTouchNav() {
    let touchStartY = 0;
    let touchStartX = 0;
    const threshold = 50;

    document.addEventListener('touchstart', (e) => {
      touchStartY = e.touches[0].clientY;
      touchStartX = e.touches[0].clientX;
    }, { passive: true });

    document.addEventListener('touchend', (e) => {
      const deltaY = touchStartY - e.changedTouches[0].clientY;
      const deltaX = touchStartX - e.changedTouches[0].clientX;

      // Only handle vertical swipes (ignore horizontal)
      if (Math.abs(deltaY) > Math.abs(deltaX) && Math.abs(deltaY) > threshold) {
        if (deltaY > 0) {
          this.goToSlide(this.currentSlide + 1);
        } else {
          this.goToSlide(this.currentSlide - 1);
        }
      }
    }, { passive: true });
  }

  setupProgressBar() {
    this.progressFill = document.querySelector('.progress-fill');
    this.updateProgressBar();
  }

  updateProgressBar() {
    if (this.progressFill && this.slides.length > 1) {
      const progress = (this.currentSlide / (this.slides.length - 1)) * 100;
      this.progressFill.style.width = progress + '%';
    }
  }

  setupNavDots() {
    const navDots = document.querySelector('.nav-dots');
    if (!navDots) return;

    this.slides.forEach((_, index) => {
      const dot = document.createElement('button');
      dot.classList.add('nav-dot');
      dot.setAttribute('aria-label', `Go to slide ${index + 1}`);
      if (index === 0) dot.classList.add('active');
      dot.addEventListener('click', () => this.goToSlide(index));
      navDots.appendChild(dot);
    });
  }

  updateNavDots() {
    const dots = document.querySelectorAll('.nav-dot');
    dots.forEach((dot, index) => {
      dot.classList.toggle('active', index === this.currentSlide);
    });
  }

  goToSlide(index) {
    if (index < 0 || index >= this.slides.length) return;
    this.slides[index].scrollIntoView({ behavior: 'smooth' });
  }

  toggleFullscreen() {
    if (!document.fullscreenElement) {
      document.documentElement.requestFullscreen().catch(() => {});
    } else {
      document.exitFullscreen();
    }
  }

  animateCounters() {
    const counters = document.querySelectorAll('[data-count-to]');
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting && !entry.target.dataset.counted) {
          entry.target.dataset.counted = 'true';
          const target = parseFloat(entry.target.dataset.countTo);
          const suffix = entry.target.dataset.countSuffix || '';
          const prefix = entry.target.dataset.countPrefix || '';
          const decimals = parseInt(entry.target.dataset.countDecimals || '0');
          const duration = 1200;
          const start = performance.now();
          const animate = (now) => {
            const elapsed = now - start;
            const progress = Math.min(elapsed / duration, 1);
            const eased = 1 - Math.pow(1 - progress, 4);
            const current = (target * eased).toFixed(decimals);
            entry.target.textContent = prefix + current + suffix;
            if (progress < 1) requestAnimationFrame(animate);
          };
          requestAnimationFrame(animate);
        }
      });
    }, { threshold: 0.5 });
    counters.forEach(el => observer.observe(el));
  }
}

// Initialize on DOM ready
document.addEventListener('DOMContentLoaded', () => new SlidePresentation());
```

## CSS Architecture Rules

1. **All typography uses `clamp()`** for responsive sizing. Never use fixed `px` or `rem` values for type.
2. **Every `<section class="slide">` is `height: 100vh; overflow: hidden`.** Content that doesn't fit is clipped. Split into multiple slides instead of cramming.
3. **`.presentation` container uses `scroll-snap-type: y mandatory`.** Each slide gets `scroll-snap-align: start`. This handles smooth slide transitions. Do not build custom scroll animation.
4. **Background uses CSS `radial-gradient`** for the dot-grid texture. No image files needed.
5. **Card containers** follow the brand kit's visual design system.
6. **Footer occupies a reserved 48px zone** at the bottom of every slide. Content area padding accounts for this (`padding-bottom: calc(var(--footer-height) + var(--slide-padding))`).

## Font Loading

The deck loads the display, body and mono faces the brand kit's typography names, from the web-font source it names (with the placeholder kit: Inter and Fira Code from Google Fonts). Put the same faces, with their fallback stacks, into `--font-display`, `--font-body` and `--font-mono` in the `:root` block, so the deck still renders offline.

If the deck will be viewed offline, you can inline the font files as base64 `@font-face` declarations, but this significantly increases file size. Default to the Google Fonts CDN approach.

## Image Handling

For fully self-contained decks, convert images to base64 data URIs:
```html
<img src="data:image/png;base64,iVBORw0KGgo..." alt="Description" />
```

For decks that will be viewed with internet access, URL references are acceptable:
```html
<img src="https://example.com/image.png" alt="Description" />
```

Ask about connectivity requirements during content discovery if images are involved.

## Aspect Ratio

Slides are designed for **16:9 widescreen** (Google Slides compatible: 10" x 5.625", 1920x1080 at export resolution). The `100vh` slide height with the viewport-base CSS ensures proper rendering at any 16:9 viewport. Content density limits in `slide-types.md` assume this ratio.
