# Vendor skills

**Asked for:** skills that drive one vendor's tool, such as Nx generators,
LaunchDarkly flags, Resend email, Cloudflare Workers, Supabase or OpenSpec.

**Why not:** they are products, not methods (SCOPE rule 2), and each vendor
maintains its own: `nrwl/nx-ai-agents-config`, `launchdarkly/ai-tooling`,
`resend/resend-skills`, `cloudflare/skills`, `Fission-AI/OpenSpec`. A copy here
would drift from the vendor's and teach agents stale commands. Install the
vendor's skills alongside this catalog.
