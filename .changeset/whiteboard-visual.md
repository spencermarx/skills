`whiteboard` leaves incubating and joins the visual family, so a bare `npx skills add` and the plugin now install it. It also takes upstream's v9.12 and v9.13. A board grows past 4,000 shapes (to 20,000 a page), and a write tldraw refuses (a full page, a locked shape) now fails its `/exec`, naming each refusal, instead of answering `ok:true` for shapes that were never drawn; a picture of more than 2,000 shapes is a captioned outline overview, and a zoom reaches full detail. Every linked worktree now shares the main checkout's boards folder, so a second server on a board is refused from any checkout, and a board's name is backed by one file: a server on another file of the same name is refused rather than attached to, a switch onto a same-named copy brings the chat along, and a name whose recorded file is gone is refused rather than reopened on a stale copy.
